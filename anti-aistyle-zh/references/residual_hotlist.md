# 二层残留热点清单

这份文件只放第一轮去味后最容易残留的高频模式。它不是禁词表；先判断词句是否承担模板功能，再决定删、压、换或保留。

## 快速路由

- 短中文、公众号、评论、方法文默认查本文件。
- 小说、提纲、强体裁只在句式残留明显时查本文件；不要让本文件压过题材专项规则。
- 命中同一热点簇 `2` 处以上，或热点簇承担段落主骨架，必须回到正文二改。
- 事实类文本只能重排和压缩原文材料，不因本文件新增事实。

## 1. `不是 A，而是 B` 型定义漂亮病

触发形态：`不是...而是...`、`不只是...更是...`、`问题不在...而在...`、`与其...不如...`。

模板功能：把复杂判断整理成漂亮二分，替读者完成辨异和升格；段落看起来更聪明，但事实推进常停住。

优先改法：

- 前后事实已经够时，直接删掉定义框。
- 把二分判断落回具体动作、后果、对象压力。
- 必要辨异只留半句，不让它成为段落主骨架。

保留例外：

- 原文确实在做术语辨析、法律界定、技术边界或政策口径。
- 人物对白里这句话本身体现角色性格或关系位置。

## 2. `真正 / 本质 / 核心 / 关键` 型替读者下判断

触发形态：`真正`、`本质`、`核心`、`关键在于`、`说到底`、`归根结底`。

模板功能：把局部观察抬成结论，让作者像在整理答案；常和段尾盖章、正反定义连用。

优先改法：

- 删除锚点词，保留其后必要事实。
- 把高位结论改成“谁做了什么 / 产生什么后果 / 卡在哪里”。
- 结尾处优先停在未完全讲圆的摩擦或代价上。

保留例外：

- 学术、技术、政策文本中确有关键变量或核心概念。
- 原文 voice_sample 本来有明确的高位判断习惯。

## 3. `往往 / 通常 / 某种程度上` 型无证泛化

触发形态：`往往`、`通常`、`某种程度上`、`从某个角度看`、`某种意义上`。

模板功能：给没有证据的判断加稳妥外壳，把个人经验或局部事实说成普遍经验。

优先改法：

- 能落回原文例子就落回例子。
- 不能举证时删掉泛化，只保留局部判断。
- 改成时间、地点、对象或行动限制。

保留例外：

- 原文确有统计、调研、制度范围或专业经验支撑。
- 评论文需要克制表达，且没有成簇出现。

## 4. `路径 / 收口 / 落地 / 闭环` 型工程复盘腔外溢

触发形态：`路径`、`收口`、`落地`、`闭环`、`对齐`、`颗粒度`、`边界`。

模板功能：把生活、人物、叙事、评论都写成项目复盘，用抽象机制代替主体、动作和后果。

优先改法：

- 改回具体动作：谁在做、谁在承受、卡在哪里。
- 非工程题材中连续出现时，优先整段降抽象。
- 保留必要专业词，但拆掉它周围的解释胶水。

保留例外：

- 技术文、产品文、工程复盘本来需要这些词。
- 原文主题就是流程、接口、系统设计或代码协作。

## 5. 正反两面都讲一遍的安全补丁

触发形态：`当然，这不是说...`、`这并不意味着...`、`不能简单理解为...`、`也不是没有...只是...`。

模板功能：为每个判断补免责条款；文本显得稳妥，但推进变慢。

优先改法：

- 删掉不影响原意的让步句。
- 把必要限制并进事实条件，不单独成段。
- 只保留真正会影响读者误解的边界。

保留例外：

- 法律、医疗、政策、学术、技术说明需要风险边界。
- 原文本来承担合规、告知或操作口径功能。

## 6. `小标题 + 冒号 + 排比建议` 型方法文模板

触发形态：`第一，...`、`更重要的是，...`、`建议：...`、`关键动作：...`、连续短标题后接命令句。

模板功能：把正文改成培训稿、课件或公众号方法卡，让每段都像在交付一个结论。

优先改法：

- 合并同功能建议。
- 删除只起主持作用的小标题。
- 留一处未讲完的摩擦，不把每项都收成方法。

保留例外：

- 用户明确要求清单、教程、FAQ、操作手册。
- 原文就是结构化说明，且标题承担检索功能。

## 7. 结尾升华型终局坡道

触发形态：`这就是...的意义`、`最终回到...`、`让...变得更加...`、`留下的不是...而是...`。

模板功能：在最后替文本盖章，把局部经验抬成普遍价值。

优先改法：

- 删掉升华句，停在具体后果、余动作或未解决的问题上。
- 评论文可停在代价和分叉，不必给总答案。
- 叙事文可停在物件、动作、沉默或下一件小事上。

保留例外：

- 演讲稿、倡议文本或明确宣传文需要动员式结尾。
- 原文已有明确结论任务，且不是空泛拔高。

## 8. 伪具体型装饰细节

触发形态：新增时间、地点、物件、动作，但不改变段落功能；一口气补齐价目、路线、工具、来路、背景；小说线索精确到像提示包。

模板功能：用具体名词伪装自然；细节没有后效，只是让段落显得像人写；事实类文本会产生越界风险。

优先改法：

- 事实类直接删掉无依据细节。
- 叙事类只留能改变动作、选择、关系或后果的细节。
- 小说线索至少让一环半失效、误导或暂时不可用。

保留例外：

- 原文已有的具体事实。
- 样文或体裁要求保留的地方性、职业性和生活质地。
